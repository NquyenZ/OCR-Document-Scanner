# 📄 OCR Document Scanner

A lightweight desktop application for extracting text from images using Optical Character Recognition (OCR) and exporting the recognized content into editable document formats

> 🚧 **Project Status:** In Development

---

## 🎯 Project Goal

The goal of **OCR Document Scanner** is to create a simple application that allows users to:

- Import an image containing text
- Process and improve the image for text recognition
- Extract text using OCR
- Review and edit the recognized text
- Export the result into different document formats

The project is designed to remain lightweight, simple to use, and easy to understand

## 🚀 Getting Started

### Requirements

- Windows
- Python 3.12
- Git
- Visual Studio Code

Clone the repository:

```bash
git clone <repository-url>
```

Enter the project directory:

```bash
cd ocr-document-scanner
```

Create a virtual environment:

```bash
py -V:3.12 -m venv .venv
```

Activate the environment:

```powershell
.\.venv\Scripts\Activate.ps1
```

Project dependencies will be added as development progresses
